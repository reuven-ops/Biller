# Help

## 1. How to ask a good question

1. Name the codes, the payer, and the state. "Can 97140 be billed with 98940 for Medicare in Florida" gets a precise answer; "can I bill manual therapy" gets a hedged one.
2. Set the date of service. Rules change on fixed dates, and the tool answers for the date you give it. The default is today.
3. Pick the provider type. A chiropractor and a physical therapist get different answers to the same question.
4. Never include patient information. No names, dates of birth, member IDs, or record numbers. The tool refuses questions that contain them and does not save the text.
5. One situation per question. Two scenarios in one question get one muddled answer.

## 2. What each evidence tier means

1. Tier 1, statute and regulation: the Federal Register and the law itself. Strongest evidence.
2. Tier 2, CMS national policy: NCCI edits and manual, fee schedules, Internet-Only Manuals, transmittals.
3. Tier 3, MAC local policy: LCDs and Articles for our jurisdictions.
4. Tier 4, payer published policy: the payer's own posted rules.
5. Tier 5, client contracts: terms for a specific client. Visible only to users assigned to that client.
6. Tier 6, our call notes: what a payer representative told us, with a reference number. Expires after a year unless reconfirmed.
7. Tier 7, our remittance experience: what actually got paid or denied, with claim counts.

Higher tiers outrank lower ones. A call note never overrides a published rule; when they disagree, the answer says so.

## 3. What abstention means and what to do next

When the tool cannot support an answer with retrieved evidence, it says "No answer" instead of guessing. That is deliberate. When it happens:

1. Read the reason. It usually names the missing source.
2. Use the Request source button. An admin sees the request and can add the source.
3. If the question is urgent, call the payer, and record what you learn as a call note so the next person benefits.

## 4. How to write a call note

1. Record the payer, the date, and the reference number the representative gave you. A note without a reference number is weak evidence in an appeal.
2. Write what was asked and what was answered, in plain words, without patient information.
3. Mark the topic codes so the note surfaces on related questions.
4. Notes expire after 365 days. Reconfirm a note when you verify it is still true; a lead approves or retires notes.

## 5. What the tool will not do

1. It will not answer without evidence. No evidence, no answer.
2. It will not show CPT descriptors, because those require an AMA license. Codes appear bare.
3. It will not accept patient information, in questions or call notes.
4. It will not pick codes from a chart. It answers rule questions; coding a visit remains human work.
5. It will not replace payer confirmation for one-off edge cases. It tells you when a call is the right next step and gives you a script.
