# Source registry: discovered URLs and retrieval dates

Filled during Phase 1 for sources 1 through 13 and 20, and during Phase 4 for payer sources. Every URL here was fetched and verified on the retrieval date shown. URLs live in config/sources.yaml; this file is the audit trail. Never cite this file as evidence; it is build documentation.

Format per source:

1. source_id
2. What was discovered: the current landing page, the file URL pattern, and the format found.
3. Retrieval date and verification note.
4. Divergence from the brief, if any.

Entries are appended during Phase 1.
